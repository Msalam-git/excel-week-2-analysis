# Excel Data Cleaning and Functions

## Project Overview
This project demonstrates the use of Microsoft Excel functions and data validation features to prepare and enhance a retail sales dataset. The project extracts information from existing columns, combines customer details, identifies high-value transactions, applies conditional formatting, and creates a controlled product-category list.

## Tools Used
Microsoft Excel
Excel Tables
Text Functions
Logical Functions
Conditional Formatting
Data Validation

## Excel Functions Applied
YEAR to extract the year from each transaction date
MID and TEXT to extract the abbreviated month
LEFT to extract the first three letters of each product category
LEN to calculate the length of each customer ID
Concatenation to combine customer ID, gender, and product category
IF to classify transactions above ₦1,000 as high value

## Tasks Completed
Extracted the transaction year
Extracted the abbreviated transaction month
Extracted the first three letters of each product category
Calculated customer ID length
Created a full customer description
Flagged high-value transactions
Applied conditional formatting to transaction amounts
Created a product-category drop-down list

## Dataset Fields 
The dataset includes transaction dates, customer IDs, customer demographics, product categories, quantities, prices, and transaction amounts.
